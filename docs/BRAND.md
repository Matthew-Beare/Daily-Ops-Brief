# MIRA brand

The user-supplied hand-mirror artwork in `assets/brand/mira-logo.png` is the canonical MIRA logo.

Use it consistently across the repository, web/PWA, Android, Windows, Linux, installers, onboarding, splash/launch surfaces, documentation, and release material. Derived sizes may be generated mechanically from the canonical PNG, but do not redesign or substitute a different mark without an explicit brand decision.

## Plain-language product identity

- **MIRA is the assistant.** The user talks to MIRA in ChatGPT and supported assistant surfaces.
- **MIRROR is the user's durable private reality/data layer.** It stores the facts, evidence, relationships, settings, history, and provenance MIRA and companion clients share.
- **The MIRA app is an optional display and ingestion companion.** It scans, photographs, uploads, displays, notifies, and provides fast physical-world interaction with the same MIRROR state ChatGPT uses.

Normal UI should use these plain-English explanations. Database/schema/record-ID/provider implementation language belongs under Advanced.

Tagline: **Reflecting reality.**
