# Meal Planning Acceptance Contract

A compliant deployment must prove:

1. existing accessible recipe/meal-plan evidence is offered for import/reconciliation before manual recreation;
2. inaccessible old chats are never claimed as read;
3. meal plan, active shopping intent and purchase history remain separate identities;
4. pantry/leftover/meal history stays in runtime state, not portable upstream source;
5. explicit user preferences drive dietary behavior and the system does not invent medical restrictions;
6. missing optional connectors degrade only their adapter path;
7. a personal customization can remain local or pass the opt-in portability/share-back gate.
